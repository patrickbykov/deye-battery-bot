# 23 — Веб-адмінка: список користувачів і схвалення

**Фаза:** 5 — Користувачі та персональні алерти
**Залежності:** 15, 22
**Блокує:** 24

## Контекст

Адмін бачить список людей, їхні ніки й обрані об'єкти, і схвалює. Те саме вже
можливо в Telegram (задача 18); веб дає огляд, якого чат не дає — усі заявки
одразу, історія рішень, експорт.

## Кроки

1. `admin-views.js` — SSR HTML шаблонними літералами, кожна функція чиста
   (`дані → рядок`), тестується без сервера. **Нуль JavaScript**, інлайновий
   CSS ~20 рядків, жодних CDN: сторінка має відкриватись із телефона в дорозі,
   а не залежати від зовнішніх ресурсів. Нуль JS дозволяє CSP `default-src 'none'`.
2. **`esc()` на кожній інтерполяції.** `first_name` — довільний Unicode від
   Telegram. Це не гіпотетичний XSS: людина ставить собі ім'я
   `<img src=x onerror=…>`, адмін відкриває сторінку. `HttpOnly` рятує cookie,
   CSP — решту, але екранування має бути першим рубежем, а не третім. Та сама
   функція обслуговує й Telegram-шлях (там вона рятує від `400 can't parse
   entities`) — один інструмент, дві проблеми.
3. Таблиця: нік, ім'я, `chat_id`, обрані об'єкти, дата заявки, статус, чекбокс.
4. **Приховане поле `known[]` зі списком відрендерених рядків.** Невідмічені
   чекбокси браузер **не надсилає взагалі**. Наївна обробка «немає в POST → не
   схвалений» означає, що адмін, який відкрив сторінку вчора й натиснув
   «Зберегти» сьогодні, зніме схвалення з усіх, кого схвалили за цей час.
   Статус змінюється тільки для `chat_id ∈ known`.
5. `303 See Other` на `/admin/users` після POST, щоб F5 не повторював дію.
6. `GET /admin/export.json` — дамп `users` + `subscriptions`. Один клік замість
   `fly ssh console`; входить у бекап-стратегію задачі 24.
7. Сторінка не має вантажити всю історію — лише поточні рядки: 256 MB.

## Критерії готовності

- [ ] `first_name` з `<script>` рендериться як текст, не виконується
- [ ] У розмітці немає жодного `<script`
- [ ] Схвалення когось у Telegram не скасовується збереженням старої сторінки
- [ ] F5 після збереження не повторює дію
- [ ] CSRF присутній у кожній формі — покрито тестом
- [ ] `export.json` містить і користувачів, і підписки
- [ ] Сторінка відкривається з телефона без зовнішніх ресурсів
