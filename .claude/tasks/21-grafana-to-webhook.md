# 21 — Перевести Grafana на вебхук

**Фаза:** 5 — Користувачі та персональні алерти
**Залежності:** 20
**Блокує:** 24

## Контекст

Код готовий — лишається під'єднати Grafana. Робиться в UI/через provisioning
API, коду не змінює.

**Наявний telegram-contact point лишається** — рішення власника. Якщо бот
лежить або вебхук зламався, адмін усе одно дізнається про проблему напряму
від Grafana. Ціна — адмін отримає два повідомлення, якщо він ще й підписник.
Нотатка в задачі 12 радила саме це.

## Кроки

1. Створити contact point типу `webhook`:
   - URL `https://deye-battery-bot.fly.dev/hooks/grafana`
   - `httpMethod: POST`
   - `authorization_scheme: Bearer`, `authorization_credentials: <токен>`
   - `max_alerts: 20` — щоб верхня межа розміру payload була керована з обох
     боків (ліміт тіла 256 KB виставлений у задачі 16)
2. У notification policy лишити **обидва** receiver'и: telegram для адміна,
   webhook для користувачів.
3. Перевірити кнопкою Test у contact point — і **подивитись реальну структуру
   payload**, вона може відрізнятись від задокументованої версією Grafana.
4. Живий тест, тим самим способом, що застосовувався 3 вер 2026:
   - тимчасово підняти поріг SOC до 99 → повідомлення має прийти адміну **і**
     схваленому підписнику, і **не** прийти `pending`. Повернути 20.
   - тимчасово звузити вікно правила простою до `-1m` → лише адмін.
     Повернути `-45m`.
5. Після переходу перевірити `lastNotifyAttemptError` обох contact point'ів:
   ```
   GET /api/alertmanager/grafana/config/api/v1/receivers
   ```
   Порожньо = доставка йде. Це єдине місце, де видно провал доставки: в UI
   правило показує здоровий `firing`, ніби все спрацювало.

## Критерії готовності

- [ ] Тестове сповіщення з UI Grafana доходить у бота (видно в `fly logs`)
- [ ] Живий алерт SOC доходить адміну **і** схваленому підписнику
- [ ] Той самий алерт **не** доходить `pending` користувачу
- [ ] Алерт застою доходить лише адміну
- [ ] `lastNotifyAttemptError` порожній в обох contact point'ів
- [ ] Пороги й вікна повернуті на робочі (20% і 45 хв)
